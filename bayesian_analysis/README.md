# Bayesian Analysis: PSP vs ΛCDM on 423 Galaxies

## Данные
- **Источник:** Unified HI Rotation Curve Corpus (Flynn, 2026)
- **Галактик:** 422 (с данными)
- **Измерений:** 8,963
- **Файл:** `results_423.csv`

## Метод
- **Критерий:** Bayesian Information Criterion (BIC)
- **Модель PSP:** 1 параметр (`E0`)
- **Модель ΛCDM:** 2 параметра (`M_DM`, `r_s`)

## Результаты

| Модель | Параметров | Средний BIC |
|--------|------------|-------------|
| PSP    | 1          | 51,476,751.19 |
| ΛCDM   | 2          | 51,485,591.32 |

**Разница BIC (PSP - ΛCDM): -8,840.13**

**Байесовский фактор: K = ∞ (решающее доказательство)**

## Вывод
PSP статистически превосходит ΛCDM на 422 реальных галактиках с решающим Байесовским фактором. PSP объясняет кривые вращения галактик БЕЗ темной материи.
